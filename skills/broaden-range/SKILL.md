# Broaden a task's range

I want useful methods from other disciplines for this task. First describe the work as actions rather than artifact names. Identify relevant disciplines, name the concrete methods and tools each would contribute, and explain what they would improve. Use their practices rather than expert personas. Then rewrite my prompt using the techniques that help my original objective, preserving its constraints and scope. Finish with the revised prompt; do not carry out the underlying task.
