# Raise altitude

Identify the outcome behind this task. Before rewriting it:

1. State what should change or which decision the work should enable.
2. Assess whether the requested deliverable is the best way to achieve that outcome.
3. Suggest a better approach where useful, including any data, access, or workflow changes it needs.
4. Explain how we could compare its effectiveness with the current approach.

Then rewrite my prompt around that outcome, preserving my explicit constraints.
