# Repository guidance

- Put each skill in `skills/<name>/SKILL.md` with YAML `name` and `description` fields. Match the name to the folder.
- Keep prompts concise and usable across agents. Describe when each skill should run; avoid dependencies on local paths or specific tools.
- Preserve supplied prompt wording unless asked to rewrite it.
- Update the README catalog when adding, removing, or renaming skills. Check frontmatter, folder names, and links.
