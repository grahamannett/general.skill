# Repository guidance

- Put each skill in `skills/<name>/SKILL.md` with YAML `name` and `description` fields. Match the name to the folder.
- Keep skills concise and usable across agents. State when each should run.
- Document required executables and authentication. Keep machine-specific paths, credentials, browser/profile choices, and permission guidance in local configuration outside reusable skills.
- Preserve supplied prompt wording unless asked to rewrite it.
- Update the README catalog when adding, removing, or renaming skills. Check frontmatter, folder names, and links.
